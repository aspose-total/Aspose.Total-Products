- Muat file WORD sumber menggunakan kelas [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
- Buat instance [HtmlSaveOptions](https://reference.aspose.com/words/python-net/aspose.words.saving/htmlsaveoptions/)

- Tentukan [SaveFormat](https://reference.aspose.com/words/python-net/aspose.words/saveformat/) sebagai MHTML
- Panggil metode `save` sambil menentukan jalur file keluaran & SaveFormat sebagai parameter. Jadi file WORD Anda dikonversi ke MHTML di jalur yang ditentukan.
