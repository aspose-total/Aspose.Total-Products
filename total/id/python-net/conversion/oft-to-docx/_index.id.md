Kedua, muat HTML yang dikonversi menggunakan [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) dan simpan ke dalam format DOCX.

- Sekarang Muat file HTML yang disimpan menggunakan [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
