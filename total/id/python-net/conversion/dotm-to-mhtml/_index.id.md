Tetapi jika ada kebutuhan untuk mengembalikan model dokumen sedekat mungkin dengan aslinya maka ada kebutuhan untuk menyimpan beberapa informasi tambahan dalam dokumen yang dihasilkan yang disebut informasi bolak-balik.

{{% blocks/products/pf/agp/feature-section-col title="Bagaimana caranya? Konversi DOTM ke MHTML dengan Python" %}}
- Muat file DOTM sumber menggunakan kelas [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
- Buat instance [HtmlSaveOptions](https://reference.aspose.com/words/python-net/aspose.words.saving/htmlsaveoptions/)
- Atur export_roundtrip_information sebagai True
- Tentukan [SaveFormat](https://reference.aspose.com/words/python-net/aspose.words/saveformat/) sebagai MHTML
- Panggil metode `save` sambil menentukan jalur file keluaran & SaveFormat sebagai parameter. Jadi file DOTM Anda dikonversi ke MHTML di jalur yang ditentukan.
