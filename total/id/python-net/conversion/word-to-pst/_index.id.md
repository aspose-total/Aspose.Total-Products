Ini adalah proses dua langkah, pertama-tama muat file WORD dan render ke HTML melalui [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Kedua, muat HTML yang dikonversi menggunakan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) dan simpan ke dalam format PST.

- Sekarang Muat file HTML yang disimpan menggunakan MailMessage.load
- Panggil metode simpan dengan jalur file yang relevan. Jadi akhirnya WORD dikonversi
