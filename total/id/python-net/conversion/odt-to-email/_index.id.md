API [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) dan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) yang merupakan bagian dari paket [Aspose.Total for Python via .NET](https://products.aspose.com/total/python-net/) memudahkan konversi ini menggunakan Python. Ini adalah proses dua langkah, pertama-tama muat file ODT dan render ke HTML melalui [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Kedua, muat HTML yang dikonversi menggunakan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) dan simpan ke dalam format EMAIL.

{{% blocks/products/pf/agp/feature-section-col title="Cara Mengonversi ODT ke EMAIL dengan Python" %}}

- Buka file ODT sumber menggunakan kelas [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
- Panggil metode `save` saat menentukan jalur file HTML keluaran dan opsi Simpan HTML yang relevan sebagai parameter. Jadi file ODT Anda dikonversi ke HTML di jalur yang ditentukan
- Sekarang Muat file HTML yang disimpan menggunakan MailMessage.load
- Panggil metode simpan dengan jalur file yang relevan. Jadi akhirnya ODT dikonversi
