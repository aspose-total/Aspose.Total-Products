- Muat file OTT sumber menggunakan kelas [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)

- Tentukan [SaveFormat](https://reference.aspose.com/words/python-net/aspose.words/saveformat/) sebagai MHTML
- Panggil metode `save` sambil menentukan jalur file keluaran & SaveFormat sebagai parameter. Jadi file OTT Anda dikonversi ke MHTML di jalur yang ditentukan.
