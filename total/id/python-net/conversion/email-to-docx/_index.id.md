Ini adalah proses dua langkah, pertama-tama muat Email dan render ke HTML melalui [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/). Kedua, muat HTML yang dikonversi menggunakan [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) dan simpan ke dalam format DOCX.

{{% blocks/products/pf/agp/feature-section-col title="Cara Mengonversi EMAIL ke DOCX dengan Python" %}}

- Buka file EMAIL sumber menggunakan kelas MailMessage.load
- Panggil metode `save` saat menentukan jalur file HTML keluaran dan opsi Simpan HTML yang relevan sebagai parameter. Jadi file EMAIL Anda dikonversi ke HTML di jalur yang ditentukan
- Sekarang Muat file HTML yang disimpan menggunakan [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
- Panggil metode simpan dengan jalur file yang relevan. Jadi akhirnya EMAIL dikonversi
