Kedua, muat HTML yang dikonversi menggunakan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) dan simpan ke dalam format EMAIL.

- Sekarang Muat file HTML yang disimpan menggunakan MailMessage.load
- Panggil metode simpan dengan jalur file yang relevan. Jadi akhirnya FLATOPC dikonversi
