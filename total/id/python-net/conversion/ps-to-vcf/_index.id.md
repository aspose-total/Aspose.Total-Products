Ini adalah proses dua langkah, pertama-tama muat file PS dan render ke HTML melalui [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Kedua, muat HTML yang dikonversi menggunakan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) dan simpan ke dalam format VCF.

{{% blocks/products/pf/agp/feature-section-col title="Cara Mengonversi PS ke VCF dengan Python" %}}

- Buka file PS sumber menggunakan kelas [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
- Panggil metode `save` saat menentukan jalur file HTML keluaran dan opsi Simpan HTML yang relevan sebagai parameter. Jadi file PS Anda dikonversi ke HTML di jalur yang ditentukan
- Sekarang Muat file HTML yang disimpan menggunakan MailMessage.load
- Panggil metode simpan dengan jalur file yang relevan. Jadi akhirnya PS dikonversi
