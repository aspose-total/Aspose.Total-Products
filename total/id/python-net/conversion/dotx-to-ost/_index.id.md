Untuk pengembang Python, siapa yang mencoba menambahkan fitur konversi DOTX ke OST dalam aplikasi? [Aspose.Total for Python via .NET](https://products.aspose.com/total/python-net/) API dapat membantu mengotomatiskan proses konversi. Ini adalah paket lengkap dari berbagai API yang menangani berbagai format termasuk format Email, Gambar, dan Microsoft Word. API [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) dan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) yang merupakan bagian dari paket [Aspose.Total for Python via .NET](https://products.aspose.com/total/python-net/) memudahkan konversi ini menggunakan Python. Ini adalah proses dua langkah, pertama-tama muat file DOTX dan render ke HTML melalui [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Kedua, muat HTML yang dikonversi menggunakan [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) dan simpan ke dalam format OST.

{{% blocks/products/pf/agp/feature-section-col title="Cara Mengonversi DOTX ke OST dengan Python" %}}

- Buka file DOTX sumber menggunakan kelas [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
- Panggil metode `save` saat menentukan jalur file HTML keluaran dan opsi Simpan HTML yang relevan sebagai parameter. Jadi file DOTX Anda dikonversi ke HTML di jalur yang ditentukan
- Sekarang Muat file HTML yang disimpan menggunakan MailMessage.load
- Panggil metode simpan dengan jalur file yang relevan. Jadi akhirnya DOTX dikonversi
