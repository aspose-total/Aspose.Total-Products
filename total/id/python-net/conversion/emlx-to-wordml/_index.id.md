Ini adalah proses dua langkah, pertama-tama muat Email dan render ke HTML melalui [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/). Kedua, muat HTML yang dikonversi menggunakan [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) dan simpan ke dalam format WORDML.
