Pour un développeur Python, qui essaie d'ajouter une fonction de conversion DIF en MOBI dans l'application. L'API [Aspose.Total for Python via .NET](https://products.aspose.com/total/python-net/) peut aider à automatiser le processus de conversion. C'est principalement en deux étapes. Utilisez d'abord l'API [Aspose.Cells for Python via .NET](https://products.aspose.com/cells/python-net/) pour convertir le fichier DIF en HTML. Après cela, en utilisant l'API Word Python [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/), enregistrez le code HTML créé au format Microsoft Word souhaité.

{{% blocks/products/pf/agp/feature-section-col title="Comment convertir DIF en MOBI en Python" %}}
- **Étape 1** Ouvrez le fichier DIF source à l'aide de la classe Workbook
- Enregistrez le fichier DIF au format HTML en utilisant la méthode save(file, SaveFormat.HTML) en fournissant le nom du fichier et le chemin du répertoire souhaité
-  **Étape 2** Charger le fichier HTML avec une instance de la classe [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
-  Appelez la méthode `save` tout en spécifiant le chemin du fichier MOBI de sortie. Ainsi, votre fichier DIF est converti en MOBI au chemin spécifié
