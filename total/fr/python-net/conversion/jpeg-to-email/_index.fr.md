C'est un processus en deux étapes, chargez d'abord le fichier JPEG et rendez-le en HTML via [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Ensuite, chargez le HTML converti en utilisant [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) et enregistrez-le au format EMAIL.
