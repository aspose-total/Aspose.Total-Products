Είναι μια διαδικασία δύο βημάτων, πρώτα φορτώστε το αρχείο TEXT και αποδώστε το σε HTML μέσω του [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Δεύτερον, φορτώστε το μετατρεπόμενο HTML χρησιμοποιώντας το [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) και αποθηκεύστε το σε μορφή OST.
