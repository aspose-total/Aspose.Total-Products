Het is een volledig pakket van verschillende API's die verschillende formaten behandelen, waaronder Microsoft Word-formaten, webarchief MHTML, HTML en HtmlFixed-formaat om het document op te slaan in het HTML-formaat met behulp van absoluut gepositioneerde elementen. [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) API die deel uitmaakt van het [Aspose.Total for Python via .NET](https://products.aspose.com/total/python-net/)-pakket, maakt deze conversie gemakkelijk te exporteren en importeren MHTML, PDF en verschillende andere formaten met behulp van Python.

- Open het bron-MHTML-bestand met de klasse [Document](https://reference.aspose.com/words/python-net/aspose.words/document/)
