É um processo de duas etapas, primeiro carregue o arquivo FLATOPC e o renderize em HTML via [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). Em segundo lugar, carregue o HTML convertido usando [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) e salve-o no formato VCF.
