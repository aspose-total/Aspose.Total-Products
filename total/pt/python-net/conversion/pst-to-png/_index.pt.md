É um processo de duas etapas, primeiro carregue o e-mail e o renderize em HTML via [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/). Em segundo lugar, carregue o HTML convertido usando [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) e salve-o no formato PNG.
