Es un proceso de dos pasos, primero cargue el archivo EPUB y transfiéralo a HTML a través de [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/). En segundo lugar, cargue el HTML convertido usando [Aspose.Email for Python via .NET](https://products.aspose.com/email/python-net/) y guárdelo en formato VCF.
