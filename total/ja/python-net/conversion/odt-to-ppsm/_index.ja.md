Python API を使用すると、ODT から PPSM への変換は、専門的なレポート作成や配信ワークフロー向けにスケーラブルなプレゼンテーション対応出力の生成をサポートします。高度な文書からスライドショーへの自動化プロセスを効率化するのに役立ちます。
