アプリケーション内に XLAM から DOTX への変換機能を追加しようとしている Python 開発者向け。 [Aspose.Total for Python via .NET](https://products.aspose.com/total/python-net/) API は、変換プロセスの自動化に役立ちます。 XLAM や DOTX ファイルなど、さまざまな形式を扱うさまざまな API の完全なパッケージです。

主に2段階です。 まず [Aspose.Cells for Python via .NET](https://products.aspose.com/cells/python-net/) API を使用して XLAM ファイルを HTML に変換します。 その後、Word Python API [Aspose.Words for Python via .NET](https://products.aspose.com/words/python-net/) を使用して、作成した HTML を任意の Microsoft Word 形式で保存します。

{{% blocks/products/pf/agp/feature-section-col title="Python で XLAM を DOTX に変換する方法" %}}
- **ステップ1** Workbook クラスを使用してソース XLAM ファイルを開く
- ファイル名と目的のディレクトリ パスを指定して、save(file, SaveFormat.HTML) メソッドを使用して XLAM ファイルを HTML に保存します。
-  **ステップ2** [Document](https://reference.aspose.com/words/python-net/aspose.words/document/) クラスのインスタンスを含む HTML ファイルをロードする
-  出力 DOTX ファイルのパスを指定して、`save` メソッドを呼び出します。 したがって、XLAM ファイルは指定されたパスで DOTX に変換されます
