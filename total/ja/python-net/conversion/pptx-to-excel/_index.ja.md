主に2段階です。 まず [Aspose.Slides for Python via .NET](https://products.aspose.com/slides/python-net/) API を使用して PPTX ファイルを HTML に変換します。 その後、Excel Python API [Aspose.Cells for Python via .NET](https://products.aspose.com/cells/python-net/) を使用して、作成した HTML を目的の Microsoft Excel 形式で保存します。
